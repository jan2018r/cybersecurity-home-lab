# Cybersecurity Home Lab

A growing portfolio of hands-on IT and cybersecurity exercises.
I am building practical skills in Linux, networking, security
investigation, and troubleshooting.

## Learning Goals

- Set up and maintain a virtual lab.
- Troubleshoot network connectivity.
- Understand Linux accounts and file permissions.
- Analyze lab network traffic using Wireshark.
- Document findings clearly and verify solutions.

## Troubleshooting Process

1. Understand the problem and its impact.
2. Identify symptoms and collect evidence.
3. Isolate the affected component.
4. Test possible causes one change at a time.
5. Resolve the issue and verify the result.
6. Document the solution and lessons learned.

## What Each Lab Will Include

- Objective and tools used
- Steps taken and reasons behind them
- Screenshots and results
- Problems encountered and troubleshooting
- Verification and lessons learned
- References and any tutorial or AI assistance used
